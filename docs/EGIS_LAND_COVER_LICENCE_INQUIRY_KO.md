## 1. 짧은 버전 (게시판 웹폼용)

> **제목:** 세분류 [2025] 토지피복지도(벡터 SHP) 이용조건 및 공공누리 유형 문의

안녕하십니까.
공익 목적의 폐기물 형평성 분석 플랫폼(Waste Equity Platform)을 개발·연구하고 있는 이용자입니다.

환경공간정보서비스 온라인 자료신청을 통해 **세분류 [2025] 전국 토지피복지도** 중
**서울특별시·인천광역시·경기도** 벡터(SHP) 자료를 내려받아 분석에 활용하고 있습니다.

현재 이 자료는 **내부 분석 용도로만** 사용하고 있으며, 공개 서비스에는 반영하지 않은 상태입니다.
「저작권 정책」 ②항에 **"공공누리가 부착되지 않은 자료를 사용하려면 담당자와 사전에 협의"**
하도록 안내되어 있어, 아래 사항을 문의드립니다.

1. 위 **다운로드 벡터(SHP) 자료**에 적용되는 **공공누리 유형**이 있습니까? 있다면 몇 유형입니까?
   (공공데이터포털에 등록된 **"토지피복지도 맵 서비스(WMS)"**는 제1유형으로 표시되어 있으나,
   이는 WMS 서비스에 대한 표시로 이해하고 있습니다. **다운로드 벡터 자료에도 동일하게 적용되는지**
   확인 부탁드립니다.)
2. 원본 SHP 파일이나 원본 도형은 일절 공개·재배포하지 않고, **500 m 격자 단위로 집계한 2차 통계**
   (피복 여부, 피복률, 대표 분류코드·분류명, 분류별 면적)만 **공개 웹지도·공개 API로 제공**하는 것이
   가능합니까?
3. 위 2차 통계를 **상업적으로** 이용하는 것도 가능합니까?
4. 이용이 가능하다면 **출처 표시 문구**를 어떻게 적는 것이 정확합니까?
5. 위 내용의 **근거가 되는 약관·지침·정책 문서**를 알려주실 수 있습니까?

가능하시면 전화가 아닌 **서면(게시판 답변)으로 회신**해 주시면 감사하겠습니다.

## 2. 전체 버전 (공문 / 이메일 / 게시판 상세 문의용)

> **제목:** 세분류 [2025] 전국 토지피복지도(다운로드 벡터 SHP) 이용범위 및 공공누리 유형 확인 요청

### 2.1 문의 배경

안녕하십니까.
저희는 수도권(서울·인천·경기)의 폐기물 처리시설 입지와 지역 간 부담 형평성을 분석하는
**공익 목적 연구·서비스 프로젝트 "Waste Equity Platform"**을 개발하고 있습니다.

귀 서비스의 「저작권 정책」에는

- ①항 — 저작재산권 전부를 보유한 저작물은 **"공공누리 제1유형"을 부착하여 개방**하고 있으므로
  **공공누리 표시 부착 여부를 확인한 후** 자유이용할 것,
- ②항 — **공공누리가 부착되지 않은 자료**를 사용하려면 **담당자와 사전에 협의**할 것

이라고 안내되어 있습니다.

저희가 확인한 바로는, 저희가 내려받은 **다운로드 벡터(SHP) 토지피복지도**에는
환경공간정보서비스 홈페이지 상 **공공누리 표시가 부착되어 있지 않았습니다.**
따라서 ②항에 따라 사전 협의를 요청드리며, 아래 사용 형태별로 가부를 확인해 주시기를 요청드립니다.

### 2.2 대상 자료

| 항목 | 내용 |
| --- | --- |
| 제공기관 | 기후에너지환경부 환경공간정보서비스(EGIS) |
| 자료명 | **세분류 [2025] 전국 토지피복지도** |
| 분류 수준 | 세분류(Level 3) |
| 기준연도 | 2025 |
| 취득 범위 | **서울특별시 · 인천광역시 · 경기도** |

| 취득 방법 | 홈페이지 온라인 자료신청 → 다운로드 |
| 취득 시점 | `[    ]` *(다운로드 내역으로 확인 후 기재. 미확인 시 "확인 중"으로 기재)* |

### 2.3 저희가 수행한 가공 내용

1. 원본 좌표계(EPSG:5186)를 **EPSG:4326으로 변환**하고, 원본에 존재하는 일부 비정상 폴리곤을
   **기하학적으로 보정(MakeValid)** 하여 내부 데이터베이스에 적재하였습니다.
2. **본 프로젝트가 독자적으로 생성한 500 m 후보지 격자**(폐기물 처리시설 적합성 분석용 격자,
   토지피복지도와 무관하게 이미 존재하던 격자)와 **교차 연산**하여,
   격자 1칸마다 다음의 **집계 통계**를 산출하였습니다.
   - 해당 격자가 토지피복 자료로 덮이는지 여부(피복 상태)
   - 피복률(0~1)
   - 평가 면적 / 미피복 면적
   - 대표 분류코드 및 분류명(대분류/중분류/세분류)
   - 분류별 면적 분포
3. 산출 규모: **격자 47,893칸**, **분류별 면적 행 1,142,780건** (원본 피처 6,901,309개로부터 집계).

### 2.4 저희가 계획하고 있는 서비스 형태 (정확한 사실만 기재)

- **원본 SHP 파일은 다운로드로 제공하지 않습니다.**
- **원본 도형(폴리곤)과 원본 속성은 외부에 공개하지 않습니다.** 현재 API 설계상 원본 도형·원본
  피처 속성은 **어떤 응답으로도 반환되지 않습니다.**
- 공개 웹지도에는 **본 프로젝트의 500 m 격자 도형** 위에 **피복 상태와 대표 분류**를 표시하는
  형태를 검토하고 있습니다. (지도에 표출되는 도형은 토지피복지도의 도형이 아니라 저희 격자입니다.)
- 공개 API로는 **격자 단위 집계 통계**를 제공하는 것을 검토하고 있습니다.
- 지도 표출 성능을 위해 **벡터 타일(MVT)** 방식을 사용하며, **브라우저·중계 서버 캐시**가
  발생합니다.
- 이 자료는 현재 **설명용 참고 정보**로만 사용하며,
  **입지의 법적 적격 여부 판단에 사용하지 않습니다.**
- 이 자료는 현재 **적합성 점수·순위·제외 판정에 사용하지 않습니다.**
- 서비스는 향후 **국내외 클라우드 서버(OCI)** 에서 운영될 수 있습니다.
- 공개 시에는 **출처 표시와 이용조건 안내를 화면에 게시**할 예정입니다.

## 4. 후속 문의 버전 (1차 답변이 불명확할 경우)

> **제목:** [재문의] 세분류 [2025] 토지피복지도 벡터 자료 — 항목별 이용 가부 재확인 요청

안녕하십니까. `[    ]`(1차 문의일자)에 문의드린 건에 대한 답변 감사합니다.

다만 회신 내용만으로는 아래 사항을 판단하기 어려워 재차 확인을 요청드립니다.
**저희는 이용조건이 확인되기 전까지 해당 자료를 공개 서비스에 반영하지 않고 있습니다.**

1. 회신에서 언급하신 이용조건이 **다운로드 벡터(SHP) 자료**에 적용되는 것입니까,
   아니면 **WMS 맵 서비스**에 적용되는 것입니까?
2. 해당 자료에 **공공누리 유형이 지정되어 있는지** 여부만이라도 **"제○유형" 또는 "지정 없음"**
   으로 명확히 알려주실 수 있습니까?
3. **원본을 공개하지 않고 500 m 격자로 집계한 2차 통계만 공개**하는 형태가 허용되는지에 대해
   **가능/불가**로 답변해 주실 수 있습니까?
4. **상업적 이용**과 **2차적저작물 작성**에 대해 각각 **가능/불가**로 답변해 주실 수 있습니까?
5. 근거가 되는 **문서명 또는 조항**을 알려주실 수 있습니까?

담당 부서가 다르다면 **담당 부서를 안내**해 주시면 그쪽으로 다시 문의드리겠습니다.
감사합니다.
